# 150 Attività Cattoliche per Bambini

Landing page italiana para o produto digital **150 Attività Cattoliche per Bambini**.

## Estrutura

- `index.html` — página principal
- `assets/style.css` — estilos responsivos
- `assets/script.js` — popup da oferta Premium
- `assets/` — imagens otimizadas do produto e dos bônus

O projeto é estático e pode ser publicado diretamente na Vercel, sem etapa de build.
